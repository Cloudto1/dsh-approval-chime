## 3. 前台规则（判据一行未改）

| 窗口状态 | 请求数 |
| --- | --- |
| 前台且聚焦 | **0** |
| 隐藏 / 失焦 / 回前台 | 各 **1** |

回前台只**撤除**（`revoke`），**不回答**审批。`pageInForeground` 的逐窗口状态表（前台/失焦/最小化/托盘隐藏/遮挡）在 rev-29 补齐了壳侧 `file:line` 出处；**托盘隐藏/最小化/被遮挡与"焦点落在侧栏嵌入式浏览器帧里"仍属运行时行为、需人眼实测**（不写成 0.2.0 的缺陷）。

## 4. 轮询语义（t11 冻结，rev-29 未改）

* **瞬时失败**（fetch 抛错）：只计数、写诊断、**保留 token**、下一 tick 照常轮询。
* 收到 **`skipped`**：**立刻放弃**该 token —— 不再轮询、也**不发撤销**。
* 两条各有能变红的负控（见 `verify/native-toast.test.mjs` §11）。

## 5. 平台可观测（rev-29 新增，只报告事实）

* `desktopPlatform()` / `diagnostics.platform()`：唯一来源 `document.documentElement.dataset.platform`，取不到即 `null`，**没有任何分支读它**。
* `diagnostics.nativeToast`：`state()` 给出开关、宿主上次安装判定、带 `timer` 标记的活 token 表与全部计数器；`tokens()` / `refresh()` / `revoke(reason)`。
